# Planned capability roadmap

The local infrastructure maintains explicit `architecture_only` state with empty capability and claim inventories. Planned evidence work includes manifests, signed statements, trust snapshots, registry snapshots, group certificates, target descriptors, adapter conformance and Studio mappings.

Each capability needs a complete owned schema, semantic refusal criteria, independently supplied vectors, real producer/consumer integration and independent verification before qualification. Signing additionally requires explicit key, trust and operational authority. Registry, deployment and hosted-service changes require separate acceptance evidence.

Portable evidence should preserve exact source bytes, provenance, licensing, unknown states and immutable object references. Scientific verdicts remain with their owning verifier. A generated declaration cannot establish implemented support.
